# Habbos v2 Landing Widget

TypeScript and HTML Canvas replacement for the Flash-based `habbos_v2.swf` landing widget. It keeps the original 396x377 stage, extracts the embedded SWF UI bitmaps, and loads promo Habbo data from the same XML endpoint used by Lisbon/Havana-style sites.

## Requirements

- Node.js 18+
- npm

## Building

```bash
npm install
npm run build
```

The build runs the SWF asset extractor, type-checks the TypeScript, builds the Vite IIFE bundle, and creates:

- `dist/habbos-v2-landing.iife.js`
- `dist/index.html`
- `dist/assets.zip`

For local development with hot reload:

```bash
npm run dev
```

Open the Vite URL printed by the command.

## Assets

The source SWF embeds only the widget UI sprites. `npm run extract-assets` reads `habbos_v2.swf` and writes those sprites to `assets/ui/`:

- `bg-top.png`
- `bg-bottom.png`
- `button-bg.png`
- `button-arrow.png`
- `loading-1.png` through `loading-4.png`

`npm run bundle-assets` packs the runtime assets into `assets/assets.zip` for local dev and `dist/assets.zip` for production.

Promo avatars are not generated by this project. The widget loads them from the configured promo XML endpoint.

## Promo XML

The default demo config points to:

```text
/xml/promo_habbos.xml
```

This matches the Lisbon landing page convention. The runtime supports both known XML shapes:

```xml
<habbos>
  <habbo image="http://localhost/habbo-imaging/avatarimage?figure=..." />
</habbos>
```

and:

```xml
<habbos url="http://localhost/habbo-imaging/avatar/">
  <habbo gender="m" figure="..." hash="..." />
</habbos>
```

If the configured URL 404s or Vite returns the HTML fallback during local development, the widget falls back to `demo/foobar/promo_habbos.xml`.

## Usage

### Lisbon-style embed

```html
<div id="create-habbo-html5"></div>
<script>
  HabboView.add(function() {
    var container = document.getElementById("create-habbo-html5");
    if (!container || !window.HabboLandingWidget) {
      return;
    }

    new window.HabboLandingWidget(container, {
      assetsPath: "/habbo-widgets/landing/",
      assetsZipUrl: "/habbo-widgets/landing/assets.zip",
      habbosUrl: "/xml/promo_habbos.xml",
      buttonLink: "/register",
      createButtonText: "Register today! " + String.fromCharCode(187),
      slogan: "Hotel is a virtual world where you can meet and make friends!"
    });
  });
</script>
<script src="/habbo-widgets/landing/habbos-v2-landing.iife.js"></script>
```

### Auto-init embed

```html
<div id="habbos-v2-container"></div>
<script>
  window.HabbosV2LandingConfig = {
    container: "habbos-v2-container",
    assetsPath: "",
    assetsZipUrl: "assets.zip",
    habbosUrl: "/xml/promo_habbos.xml",
    buttonLink: "/register"
  };
</script>
<script src="habbos-v2-landing.iife.js"></script>
```

## Config Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `container` | string | `'habbos-v2-container'` | Container ID used by the auto-init path. |
| `assetsPath` | string | `''` | Base path for `assets.zip` and unpacked `ui/` fallback files. |
| `assetsZipUrl` | string | `'assets.zip'` | Lisbon-style path or URL to the asset bundle. |
| `assetBundlePath` | string | `'assets.zip'` | Legacy alias for `assetsZipUrl`. |
| `habbosUrl` | string | `''` | Lisbon-style URL to `promo_habbos.xml`. |
| `habbos_url` | string | `''` | FlashVars-compatible alias for `habbosUrl`. |
| `fallbackHabbosUrl` | string | `'demo/foobar/promo_habbos.xml'` | Local fallback XML used when the configured promo URL is unavailable. |
| `buttonLink` | string | `''` | Registration URL. The widget appends `?gender=...&figure=...`. |
| `button_link` | string | `''` | FlashVars-compatible alias for `buttonLink`. |
| `createButtonText` | string | `'Choose your habbo'` | Lisbon-style button label. |
| `select_button_text` | string | `'Choose your habbo'` | FlashVars-compatible alias for `createButtonText`. |
| `header_text` | string | `"Join now, it's free!"` | Top heading text. |
| `slogan` | string | Habbo default slogan | Bottom slogan text. |
| `debug` | boolean | `false` | Enables console diagnostics for failed asset loads. |

## Runtime API

The IIFE exposes:

```js
window.HabboLandingWidget
window.HabbosV2Landing
```

Use `HabboLandingWidget` for normal embeds:

```js
const widget = new window.HabboLandingWidget(container, {
  assetsZipUrl: "assets.zip",
  habbosUrl: "/xml/promo_habbos.xml",
  buttonLink: "/register"
});

widget.stop();
```

## Project Structure

```text
habbos_v2_landing/
  habbos_v2.swf              - Original Flash widget
  src/
    index.ts                 - Auto-init and public constructor
    config.ts                - Config aliases and defaults
    HabbosV2Landing.ts       - Canvas renderer and widget behavior
    RuntimeAssetLoader.ts    - assets.zip loading and raw fallback
    assetPaths.ts            - Shared path resolution helpers
  scripts/
    extract-assets.mjs       - Extracts embedded SWF UI bitmaps
    build-asset-bundle.mjs   - Builds assets.zip
  assets/                    - Generated runtime assets for dev
  dist/                      - Production build output
```

## Notes

This is a native HTML5 port, not a Flash emulator wrapper. The visual UI assets are extracted from `habbos_v2.swf`; promo avatar images come from the configured server-side XML and imaging endpoints.
